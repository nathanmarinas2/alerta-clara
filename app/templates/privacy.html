Privacidad y Tratamiento de Datos

Alerta Clara analiza el contenido que envías para generar un veredicto orientativo. No vende datos, no crea perfiles publicitarios ni almacena identificadores personales.

Qué guardamos y qué redactamos

Antes de guardar o evaluar cualquier mensaje, el sistema redacta automáticamente datos personales sensibles como números de tarjeta, códigos de un solo uso (OTP/PIN), identificadores nacionales (DNI/NIE), teléfonos e IBANs.

Guardamos durante un periodo de retención limitado el texto redactado, las señales técnicas calculadas y el veredicto final. La referencia del usuario se transforma en un hash con un secreto del servidor (pepper) para evitar rastreos persistentes.

Imágenes y proveedores externos

El reconocimiento de texto (OCR) y la decodificación de códigos QR se ejecutan localmente en el servidor. Las imágenes y capturas no se almacenan en disco ni se transmiten a proveedores externos salvo que se active de forma expresa y voluntaria el análisis asistido.

Tus derechos

Para solicitar información, rectificación o eliminación anticipada de cualquier registro derivado de tus análisis, contacta con la persona responsable de esta instalación. Esta página es informativa y describe el funcionamiento técnico por defecto del software de código abierto.
